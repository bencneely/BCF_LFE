This repository contains data and code for a manuscript titled "Assessing sampling effort for lentic Blue Catfish populations using low-frequency electrofishing" submitted for publication in North American Journal of Fisheries Management.

### Companion Tool
The interactive simulation below allows you to explore the sampling data directly. If the tool does not load in your browser, you can access it via the link below.
