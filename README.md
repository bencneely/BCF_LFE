This repository contains data and code for a manuscript titled "Assessing sampling effort for lentic Blue Catfish populations using low-frequency electrofishing" published in North American Journal of Fisheries Management.
https://doi.org/10.1093/najfmt/vqag009

### Companion Tool
A web-based simulation tool was developed to accompany this manuscript. This application allows users to explore sampling effort scenarios dynamically using data from Kansas populations.

[Click here to launch the Blue Catfish Sampling Simulator](https://bencneely.shinyapps.io/Blue_Catfish_sampling_simulation/)
